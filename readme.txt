== Description ==

Certificate Generator is a comprehensive WordPress plugin that allows you to create, manage, and distribute digital certificates to students. Perfect for educational institutions, training organizations, and certification programs.

**Key Features:**
* Custom certificate templates with FPDF integration
* Bulk certificate generation and distribution
* Student management system
* Email delivery with customizable templates
* CSV import/export functionality
* Search and filter capabilities
* Background processing for large batches

== Installation ==

1. Upload the plugin files to `/wp-content/plugins/certificate-generator/` directory
2. Activate the plugin through the 'Plugins' screen in WordPress
3. Go to Certificate Generator in the admin menu to configure settings
4. Start creating certificates!

== Frequently Asked Questions ==

= What file formats are supported for certificates? =
The plugin generates PDF certificates using the FPDF library.

= Can I customize certificate templates? =
Yes, you can customize fonts, colors, and layout through the admin interface.

= Is bulk certificate generation supported? =
Yes, you can generate certificates in bulk using CSV import functionality.
